    3 · The manuscript

    A book is a Book: beats of prose with locks. Either let the model draft it, or paste an existing manuscript — the build itself never needs a model (R-WIZ-007).

    4 · Build

    A build is the real typesetter — the solver measures every block in pinned Chromium, then the emitter writes one self-contained file. Expect a minute. A built book can be opened and shared on its own.
